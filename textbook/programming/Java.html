Javaの基本

Javaプログラムの基本構造は次の通り。

public class App {
    public static void main(String[] args) {
        //ここに命令を書く
    }
}

波括弧{...}で囲まれた部分をブロックという。

例

public class App {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

このコードでは「Hello, World!」と表示される。

「public class」の直後にある単語はクラス名といい、プログラムの名前を指定してる。Javaではソースファイルの名前は「クラス名.java」にしなければならない。
