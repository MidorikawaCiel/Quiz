全学問体系 ナレッジマップ

あらゆる知識・スキルを基礎から体系的に探索できます

1. 形式科学 Formal
数学 (Mathematics)
  • 代数学（基礎代数 / 線形代数 / 群論）
  • 解析学（微分積分 / 微分方程式 / 複素解析）
  • 幾何学（ユークリッド幾何 / 位相空間論）
論理学・情報理論
  • 数理論理学（命題・述語論理）
  • 計算理論・アルゴリズム論
  • 情報理論
統計学・確率論
  • 記述統計 / 推測統計
  • 確率過程・ベイズ統計
2. 自然科学 Natural
物理学 (Physics)
  • 古典力学 / 電磁気学 / 熱統計力学
  • 量子力学 / 相対性理論
化学 (Chemistry)
  • 物理化学 / 無機化学 / 有機化学
  • 高分子化学 / 分析化学
生物学 (Biology)
  • 分子生物学 / 遺伝学 / 細胞生物学
  • 植物生理学 / 生態学 / 進化生物学
地球・宇宙科学
  • 地質学 / 気象学 / 海洋学 / 天文学

工学 (Engineering)
  • 情報工学（Web開発 / AI・機械学習）

農学・生物資源科学
  • 農芸化学 / 森林・木質科学 / 水産学
  • 環境保全学・生態系管理
医学・薬学・健康科学
  • 解剖学 / 生理学 / 薬理学 / 公衆衛生学
建築・都市工学
  • 構造力学 / 建築計画 / 都市デザイン
4. 人文科学 Humanities
哲学・倫理学
  • 西洋哲学史 / 東洋哲学 / 科学哲学

  • ミクロ・マクロ経済学 / 金融論
